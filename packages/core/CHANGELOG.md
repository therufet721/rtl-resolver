# Changelog

## 0.2.0 — 2026-08-17

First coordinated npm release. Exports `./bidi` for the UAX #9 engine and
`./plugin` for `validateRTLPlugin`.

## 0.1.0 — 2026-08-17

Locale direction, script detection, mixed-content isolation, and the full
UAX #9 engine. Plugin types are on the main entry; `validateRTLPlugin` is
exported from `@rtl-resolver/core/plugin`. This is the canonical
implementation re-exported by `rtl-resolver`.
