# Changelog

## 0.2.0 — 2026-08-17

First coordinated npm release. Published JS now starts with `"use client"` so
Next.js App Router treats `DirectionProvider` as a Client Component.

## 0.1.0 — 2026-08-17

`DirectionProvider`, `useDirection()`, SSR-safe document attributes, nested
scopes, and post-mount persistence.

- Added escaping-safe semantic `<Bdi>` and `<Bdo>` renderer components.
